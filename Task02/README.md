# Task 02 – CPU Scheduling

## 1. Aim

To study and compare different CPU scheduling algorithms and understand their effect on waiting time, turnaround time, response time, and CPU utilization.

## 2. Scheduling Algorithms

The following algorithms will be studied:

- First Come First Served (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Priority Scheduling
- Round Robin (RR)

## 3. Round Robin Implementation

A C program will be implemented and executed using different time quantum values.

## 4. Performance Evaluation

Waiting time, turnaround time, response time, and context switches will be compared.

## 5. Conclusion

The scheduling algorithms will be evaluated to recommend a suitable policy for a cloud video-encoding service.
