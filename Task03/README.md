# Task 03 – Threads

## 1. Aim

To understand multithreading, thread creation, thread synchronization, and the performance benefits of using thread pools.

## 2. Thread Creation

A C program will be developed to simulate 64 camera streams using threads.

## 3. Thread Pool Experiments

The program will be tested using different thread pool sizes:

- 4 threads
- 8 threads
- 16 threads

## 4. Performance Evaluation

The experiments will compare execution time, resource usage, and speedup for different thread pool sizes.

## 5. Race Condition

A shared counter will be used to demonstrate race conditions. Synchronization will be applied to ensure correct results.

## 6. Process and Thread Comparison

Processes and threads will be compared based on memory usage, context switching, communication, and fault isolation.

## 7. Conclusion

The experiments will help identify how threads and thread pools improve the performance of concurrent applications.
